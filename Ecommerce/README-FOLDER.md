# ecommerce – E‑commerce project variants

This folder holds **e‑commerce**-style projects that are separate from the main Coding Dojo Commerce app.

- **eCommerce/** – Backend + frontend structure (e.g. Amazona-style: `backend/`, `frontend/`, screens, product data)
- **Ecommerce/** – Client + server structure (root-level `client/` and `server/` layout)

The **main** project (dojocommerce + server) lives at the repo root and is the one kept up to date.
